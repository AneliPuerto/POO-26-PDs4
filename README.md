# Sistema Administrativo de Venta de Stands - FILEY

## Descripción 
Este programa es una aplicación de escritorio desarrollada en **Java** bajo la arquitectura **Modelo-Vista-Controlador (MVC)**, diseñada para gestionar, administrar y consultar la información de los espacios de exposición de (**FILEY**).

El sistema implementa datos local utilizando una base de dato **H2** conectada mediante **JDBC**, permitiendo visualizar en tiempo real el inventario de stands, las editoriales participantes y el registro de reservaciones activas.
